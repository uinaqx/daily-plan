# daily-plan

一个单文件版每日计划工具，用来记录每天要做的任务、预计用时和完成情况。项目是纯前端实现，不需要后端服务，任务数据会自动保存在浏览器本地。

## 功能

- 添加、完成、删除每日任务
- 记录每个任务的预计分钟数
- 自动统计任务总数、已完成数量、预计总时长和已完成时长
- 环形进度展示当天完成率
- 近7天完成率趋势
- 本月完成情况视图
- 深色/浅色主题切换
- 自动保存到 `localStorage`
- 支持离线使用

## 技术特点

- 单个 `index.html` 文件即可运行
- 使用原生 HTML、CSS、JavaScript
- 不依赖后端数据库
- 不需要 npm 安装依赖
- 适合部署到 GitHub Pages

## 本地运行

直接用浏览器打开 `index.html` 即可。

为了避免某些浏览器限制，也可以启动一个本地静态服务：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 数据保存说明

任务数据保存在当前浏览器的 `localStorage` 中。

也就是说：

- 同一浏览器再次打开，数据仍然存在
- 换设备、换浏览器后，数据不会自动同步
- 清除浏览器缓存或站点数据后，任务记录可能消失

## 部署到 GitHub Pages

1. 打开仓库 Settings
2. 进入 Pages
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`，目录选择 `/root`
5. 保存后等待部署完成

## 适用场景

这个项目适合用来做个人每日计划、学习任务记录、复习安排和简单时间管理。如果需要多人同步或跨设备同步，就需要后续接入后端数据库。
